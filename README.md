# CU_DoktorMod（简体中文分支）

DoktorMod 的简体中文汉化分支，基于 Txgom2 的原项目，遵循 Apache-2.0。

- 上游项目：https://github.com/atalantisalt03/CU_DoktorMod
- 原始发布页：https://www.nexusmods.com/scavprototype/mods/666
- 本分支修改：RedAsteroid（2026）— UI 文本汉化、术语调整、少量修正
- 许可证：Apache License 2.0，全文见 LICENSE
- 署名与修改说明：见 NOTICE

## 安装
1. 安装 BepInEx 5（x64）。
2. 安装 KefPluginRuntime（随 CU-CraftingTweaks 分发，MIT 许可；本仓库不包含）。
3. 将 DoktorMod.dll 放入 BepInEx/plugins/DoktorMod/。
